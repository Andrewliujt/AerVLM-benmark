# AerVLM Benchmark

To facilitate aviation-sector researchers in gaining deeper insights into aviation scenarios, we open-source this data benchmark.

## Dataset

- **Dataset address:** [Baidu Netdisk](https://pan.baidu.com/s/1qPQKmvhLM35udPsnBQyJdw?pwd=gknr)
- **Access code:** `gknr`

## Benchmark Overview

AerVLM evaluates aviation vision-language understanding across eight target-centric capabilities:

- Target type
- Target behavior
- Target potential intention
- Target attribute
- Target quantity
- Target location
- Target state
- Target domain knowledge
